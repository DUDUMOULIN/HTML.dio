Surgimento da Internet

(Voltar)

A internet surgiu na década de 60, quando os Estados Unidos criaram uma rede de computadores para fins militares, chamada ARPANET. O objetivo era permitir a comunicação entre diferentes instituições de pesquisa e militares, mesmo em caso de ataques nucleares. Com o tempo, a ARPANET evoluiu e se expandiu, conectando universidades e com o passar do tempo foi se conectando com mais computadores até se espalhar para todo o mundo. Hoje vivemos em um mundo onde a globalização e a comunicação que antes demorava dias ou meses para receber hoje fazemos em minutos.

Como funciona o Html

(Voltar)

O html com o muitos pensam não é uma linguagem de programação já que não possui lógica de programação, o html é uma linguagem de marcação usada para estruturar o conteúdo na web, ele é a base de qualquer site ou aplicação web,muito usado na crição de blogs, o html em conjunto com o css cria sites muito mais atrativos para a os outros, e a combinação do html com o javascript cria sites dinâmicos e interativos. Você pode usar o html para criar diversos tipos de conteúdo, como textos, imagens, vídeos, links, formulários, entre outros. Para você começar a usar o html, você precisa de um editor de texto simples, como o Vscode ou o notepad++, e um navegador web para visualizar o resultado do seu código. Depois cria um arquivo com a extensão .html e começa a escrever seu código usando as tags do html.

O que são tags

(Voltar)

As tags são estruturas usadas para dar significados para a estrutura das paginas, cada tags tem sua função e trás uma estruturação dependendo de qual foi usada, veja alguns exemplos:

  • body= corpo do site html,o que aparece ao usuario;
  • head= cabeça do site html, o que não aparece ao usuario;
  • title= o titulo que aparece na janela do navegador;
  • i= deixa em italico;
  • stronge= deixa ele meio deitado;
  • input= adiciona um campo;
  • p= paragrafo
  • marke= marca o texto
  • blockquote= usado para fazer sitação
  • u=anderline
